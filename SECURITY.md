# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through GitHub:
*Security* tab → *Report a vulnerability* (GitHub Security Advisories).

Include the affected version or commit, platform, steps to reproduce and impact. A sample file that triggers the
problem is welcome (media files, project bundles).

## What to expect

| Step | Target |
| --- | --- |
| Acknowledgement | within 7 days |
| Initial assessment | within 14 days |
| Fix for high / critical severity | within 30 days, then coordinated disclosure |

## Scope

In scope: the Shorted apps and engine in this repository, release artefacts, CI workflows.
Out of scope: third-party AI providers' services, vulnerabilities in the operating system's codecs (report those
to the vendor; we will still help mitigate).
