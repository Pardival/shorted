# Derush fixtures

Labelled clips for the local derush (T-0801). Each file describes one clip: its length, where people
speak, and the dead time an editor would remove. The test builds the sound from these labels: speech
is syllable-shaped noise, the room is quiet noise at the level given, so the set runs anywhere,
without media files.

Real phone clips with hand labels should join this set: same format, plus the clip itself.
